# 🌿 GreenBin
Android-приложение для сортировки отходов и экологического просвещения.

## 🧩 Стек технологий
- Kotlin + Jetpack Compose (Material 3)
- Clean Architecture (MVVM)
- Firebase (Auth, Firestore, Storage)
- Room (локальное кэширование)
- Hilt (Dependency Injection)
- Yandex MapKit (карта пунктов переработки)

## ⚙️ Цель
Повысить осознанность пользователей в сфере переработки отходов и экологии.
